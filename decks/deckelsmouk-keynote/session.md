# Session notes

Claude's memory of this deck across conversations: it reads this when a conversation starts and adds what is
worth keeping. Edit it freely; keep it short.

## About

- The example keynote about Deckelsmouk itself: a 25-minute product keynote (28 slides + 2 backup) that tours the
  tool in the order you use it: start page and new deck → templates → editing by hand → animation → asking the LLM companion
  (select & ask, custom effects, context, fit to audience, session notes, history) → writing a whole deck from
  material → one-file export → why a turtle.
- Main message: arrange by mouse, animate by asking, ship one file.

## Decisions and preferences

- Look: the start page's paper and watercolour, after Sosthène Weis (1872–1941); loose, not precise. Assets are
  copies of editor/art/*.webp and the watercolour turtle (assets/turtle.svg).
- Serif headings (--font-heading), sans for UI; pigments via .p-ultra/.p-cerulean/.p-ochre/.p-sap/.p-madder/.p-sienna.
- Mock-ups of the editor stay dark (the editor's workshop look); the start page mock is paper.
- The deck must show off animation: every slide moves; custom effects bleed, ink-title, dab, settle, gather, brush,
  wash-in, type; slide scripts for effects (replay all), paint (canvas drops) and ask (plays the result).
- Five chapter dividers share one layout: a numbered dab (320 px) at left 200, eyebrow + h1 at left 600.
- The bee survey on the fit-to-audience slides is an illustrative example and stays labelled as such.
- Keynote audience: no bullet lists except on the deliberately dense "colleagues" example slide.
- Never name Claude (or any model) in the deck: it is "the LLM companion" (local or cloud), on slides, mock-ups and
  speaker notes. The third pillar on "Meet Deckelsmouk" is "Any LLM beside you, local or in the cloud".
